# 微信聊天记录 · 违规事项整理（证据汇编）— 自动托管版

一页式证据汇编网页（10 个类别 · 42 个事项 · 五段式结构 · 聊天原文逐行排版）。
本仓库已配好 GitHub Actions：**push 到 main 后自动发布为 GitHub Pages 网站**，无需手工部署。

## 首次上传（三步）

1. 在 GitHub 新建仓库：类型选 **Public**，名字自定（如 `evidence-dossier`），
   **不要**勾选 “Add a README file”。

2. 在本文件夹打开终端（空白处右键 → “在终端中打开”；或 Git Bash 进入本目录），执行：

   ```bash
   git remote add origin https://github.com/你的用户名/你的仓库名.git
   git push -u origin main
   ```

   首次推送会要求登录 GitHub（浏览器弹窗授权，或粘贴 Personal Access Token）。

3. 打开仓库 **Settings → Pages**，把 “Build and deployment” 的 **Source** 选为
   **GitHub Actions**（若工作流已自动开启则跳过此步）。

完成后页面地址即：

```
https://你的用户名.github.io/你的仓库名/
```

之后每次推送都会自动重新发布（一般 1 分钟内生效）；也可在仓库 **Actions** 页点一次
“Run workflow” 手动触发。

## 日常更新

双击 **更新并推送.bat**：自动重新生成页面 → 提交 → 推送，网站随之更新。
（脚本内容：调用本地生成器重建 `site/index.html` → `git add/commit` → `git push`。）

> 注：该 bat 依赖本包在「违规证据整理\_GitHub托管包」目录内的相对位置与本机 Python。
> 在别的机器上更新时，只需替换 `site/index.html`（用 `_工具\生成网页.py --脱敏 --部署版` 生成）
> 再 `git push` 即可。


## 页面说明

- 按「类别 → 事项」组织：10 个类别（职称与学术造假 / 教辅征订与商业回扣 / 发票与财经违规 /
  招生录取违规 / 学籍与借读违规 / 学生信息与成绩外泄 / 收受礼品礼金与宴请 / 有偿补课与介绍生源 /
  分班与亲属请托 / 其他违规与辅证）。
- 每个事项含：事项概述、事情发展顺序与证据链、聊天记录原文（逐行排版，红色为本人发出的消息）、
  适用规定、待核实与缺口。
- 页面功能：左侧目录、全文搜索（自动高亮）、一键折叠、打印 / 导出 PDF。

## 🎁 访问彩蛋（网站版）

- 开屏彩蛋：**全站累计前 10 次访问**显示「宋叔叔大帅比」开屏页——不同设备、不同地区都累计
  到同一个总数；累计满 10 次后**所有人**打开都直接进入正题。
- 计数依赖免费计数器（主：abacus.jasoncameron.dev，备：不蒜子），页面每次打开计 1 次；
  计数服务不可达或数值异常时**直接放行**——彩蛋属装饰功能，任何情况下都不会挡住材料查看。
- 重置计数：免费计数器没有清零接口；想重新累计就改 `_工具\生成网页.py` 里的 `EGG_NS`
  （如 `wechat-dossier-3k9f` → `wechat-dossier-3k9f-2`）后重新生成、推送。
- 改次数：改同文件里的 `EGG_LIMIT`（默认 10）；关彩蛋：删掉 `更新并推送.bat` 里的 `--彩蛋`。
- 小提醒：你自己每打开一次也消耗全站额度；想看完整效果，推送后间隔用不同设备/网络打开。
- 本地递交版（`..\违规证据汇编.html`）不含该彩蛋，保持正式材料整洁。
